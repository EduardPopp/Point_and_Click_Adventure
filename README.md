# 🎮 Point & Click Text Adventure

A web-based Point & Click Text Adventure developed as a freelance commission project, bridging the gap between custom software engineering and media design. 

🔗 **[LIVE DEMO: PLAYABLE IN BROWSER](https://eduardpopp.github.io/Point_and_Click_Adventure/)**

---

## 👥 Project Context & Collaboration
This project was built as a custom technical commission for a team of Media Designers.
* **Frontend Engineering & Game Logic:** Conceptualized and programmed entirely by me.
* **Visual Asset Design, Storywriting & UI/UX:** Provided by the design team based on their creative vision.

The core objective was to deliver a lightweight, responsive web framework that dynamically translates the designers' visual scenes, story branches, and interface layouts into a seamless browser experience without the overhead of heavy game engines.

---

## 🛠️ Technical Features & Architecture
An experienced developer looking at the source code will find the following core implementations:

* **State Management:** A custom JavaScript state engine that dynamically tracks player decisions, flags, inventory item collection, and unlocked progression paths.
* **Dynamic DOM Manipulation:** Seamless transition of scenes, text overlays, and interactive clickable zones via optimized vanilla JavaScript DOM traversal.
* **Responsive Layout:** Built with modern CSS (Flexbox/Grid) to ensure the highly stylized interface assets scale correctly across varying screen resolutions.
* **Event-Driven Interactions:** Clean event listener structures handling the user inputs, item combinations, and point-and-click mechanics efficiently.

---

## 💻 Tech Stack
* **Languages:** JavaScript (ES6+ Vanilla), HTML5, CSS3
* **Hosting/Deployment:** GitHub Pages (Automated CI/CD Pipeline via GitHub Actions)
